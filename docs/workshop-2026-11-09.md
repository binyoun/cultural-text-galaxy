# Workshop record: Counting Cultural Stars, 9 November 2026

ISEA2026 Online Academic Programme, Workshop 0735, Online Stream 4.
Facilitated by Bin Youn (RMIT University Vietnam) and Ng Yi Kee (Multimedia University).

- Public record: https://binyoun.github.io/counting-cultural-star/
- Shared sky: https://cultural-text-galaxy.onrender.com/galaxy

## What ran on the day

- The web sky (`/sky.html`, served at `/galaxy`) received 8 handwritten contributions.
- Entries were kept as sent, including a repeated name, a printed logo and a page with
  paper strips left in. Keeping them is deliberate: the record is what happened.
- Ng Yi Kee's TouchDesigner galaxy fetched entries over HTTP from `/api/entries`.
- Stars are served by Render and stored in Supabase. Google Drive held only the starter
  file and a backup folder.
- Do not run the galaxy reset: it would erase this record.
